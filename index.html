About PhishShield

PhishShield is a phishing URL analysis project with a static web front end and a Python serverless API, deployed on Vercel.

Core components

  • Explainable, rule-based URL risk analysis (19 URL features)
  • Trusted-host allowlist (including the app's own host)
  • Google Safe Browsing threat-list lookups (optional API key)
  • Scan history and risk-distribution dashboard (stored in your browser)

Limitations

  • URL patterns can create false positives and false negatives.
  • Threat intelligence may not know about a newly created phishing URL.
  • An API timeout is not evidence that a URL is safe.
  • HTTPS encrypts a connection but does not prove a site is trustworthy.
  • Trusted hosts skip URL-shape warnings, but a Safe Browsing known-threat match still overrides trust.

PhishShield is a decision-support tool, not a guarantee of safety.
